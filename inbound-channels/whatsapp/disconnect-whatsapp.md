# Disconnect WhatsApp

{% hint style="warning" %}
You must disconnect WhatsApp in both Chatlyst and the WhatsApp Business app.
{% endhint %}

{% stepper %}
{% step %}
## Disconnect WhatsApp in Chatlyst

1. Go to Inbound Channel.
2. Select the widget you want to disconnect from WhatsApp, then select **Configure**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmenta82e853c 38bb 4006 b0d0 68d895f81d1cimage.png" alt=""></div>

3. Select **Disconnect WhatsApp**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment440fdd3c b1a7 4a30 b48f 926b880b2dbeimage.png" alt=""></div>

4. When the browser confirmation window appears, select **OK** to proceed.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment8ce0bc20 2204 41d8 984d 7fb53cbff81cimage.png" alt=""></div>

5. Confirm the widget status changes from **Active** to **Draft**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmentda95bbc4 8750 42e8 ab26 0a41c884ff8aimage.png" alt=""></div>
{% endstep %}

{% step %}
## Disconnect WhatsApp in WhatsApp Business

1. Open **WA Business** on your phone.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmentfcb8a523 2f93 4640 9cb6 76e1136e84e3image.png" alt="" width="375"></div>

2. Go to **Settings**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment5d552174 02a5 4f48 ab21 84bb6c1d034cimage (1).png" alt="" width="375"></div>

3. Go to **Account**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment7ddf24bc 2445 4141 b816 7d160c37e523image.png" alt="" width="375"></div>

4. Select **Business Platform**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmenta1787ba7 a044 47d6 8b2f e59b5d385da9image.png" alt="" width="375"></div>

5. Under Connected platform, select Effex.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmentc1d5514f d7f5 4bd9 b3f4 beefc3cc7ffbimage.png" alt="" width="375"></div>

6. Select **Disconnect**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmentbbfba4b5 aa8d 4bb6 9074 3d9a2c876bb0image.png" alt="" width="375"></div>

7. Select **Next** to proceed.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment2f047f0d ed88 4b1b bd01 403365f2a42aimage.png" alt="" width="375"></div>

8. Select **Disconnect**. WhatsApp Business will show Disconnecting.

![](<../../.gitbook/assets/attachmentc590b4cb 13b6 4245 8f3e ec2ce26bd0cdimage.png>) ![](<../../.gitbook/assets/attachmentf2f0c107 4914 44a6 b2ba a0b1c5160134image.png>)

9. When the previous step is complete, you will see the following on your phone.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment9f8fc2c7 5da9 4093 999b e39226a8f007image.png" alt="" width="375"></div>
{% endstep %}
{% endstepper %}
