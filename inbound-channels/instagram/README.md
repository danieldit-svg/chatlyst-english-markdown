## Important Notes:

#### **Prerequisite for Connection**

Before connecting an Instagram account to Chatlyst, two specific requirements must be completed within the Meta platform. Ensure the following steps are finished before proceeding:

#### 1. Adding an Instagram Account to Meta Business Suite

Before connecting an Instagram account to Chatlyst, the account must first be linked to an active Meta Business Suite.

{% hint style="warning" %}
Only Instagram professional accounts can be added to a Meta Business Suite portfolio. If a personal account is added during this process, the system will automatically convert it into a professional account.
{% endhint %}

**Steps to add the account:**

{% stepper %}
{% step %}
Log in to the **Meta Business Suite** and Navigate to the **Settings** menu.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (723) (1).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Locate the **Accounts** section and select **Instagram accounts**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (725).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select the **Add** button. Follow the guided on-screen instructions provided by Meta to finish adding the account.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (726).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

#### **2. Connecting** an Instagram Account **to a Facebook Page**

After successfully adding the Instagram account to Meta Business Suite, the next requirement is to link it directly to an active Facebook Page.

**Steps to connect the account:**

{% stepper %}
{% step %}
Log in to the **Meta Business Suite** and Navigate to the **Settings** menu.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (727).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Locate the **Accounts** section and select **Pages**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (970).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select the specific Facebook Page intended for the Instagram connection from the provided list. Select **Connect assets**, then choose the **Instagram account** option.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (969).png" alt=""><figcaption></figcaption></figure></div>

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (733).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select **Log into Instagram**. Follow the guided on-screen instructions provided by Meta to complete the connection process.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (734).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

#### Instagram 3-Way Synchronisation

If you registered using the Instagram App, you will retain full access to the application. Messages are synchronized across both Chatlyst ([Chat](https://app.gitbook.com/s/BW7n4ClAhZvbgvusylCd/chat) section) and the Instagram App.

#### **Message History**

Chatlyst does not sync historical messages from the Instagram. Only messages within active Chatlyst sessions will be visible in the platform.

## Manage Widgets

### **Widget On/Off**

Use the switch in the top-right corner to turn a channel on or off.

When a channel is turned off, it is disabled immediately, and the chatbot stops appearing on that channel.

Any widgets connected to the channel automatically change from **Active** to **Draft**. This removes them from the live experience until the channel is enabled again.

<div><figure><img src="../../.gitbook/assets/image (702) (1).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (701) (1).png" alt=""><figcaption></figcaption></figure></div>

### **Recent Metrics**

The tab shows the number of conversations and messages from the past 30 days. Use these metrics to confirm the channel is receiving traffic and validate performance before making configuration updates.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (704) (1).png" alt="" width="375"><figcaption></figcaption></figure></div>

### **Add and Configure Widget**

To add a widget, select **Add Widget (Connect Instagram Account)** to launch the widget setup flow. For additional context, follow [Add a Widget](add-a-widget.md).

1. The guided setup walks through:
   * Entering the widget’s key details.
   * Reviewing the default settings.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (706) (1).png" alt="" width="375"><figcaption></figcaption></figure></div>

2. To configure a widget, select the widget from the list, then select **Configure** to open the widget setup and review its configuration. For additional context, follow [Configure a Widget](configure-a-widget.md).

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (705) (1).png" alt="" width="375"><figcaption></figcaption></figure></div>

{% hint style="warning" %}
**Important Note**: All widgets share the same Business Knowledge base. This means updates to your Business Knowledge apply to every widget, so users do not need to maintain separate knowledge for each one.
{% endhint %}
