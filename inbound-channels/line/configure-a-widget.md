# Configure a Widget

In LINE, select the widget from the list and select **Configure** to open the widget Overview page.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (419).png" alt="" width="375"><figcaption></figcaption></figure></div>

On this page, key stats include total conversations, total messages, and average session duration.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (420).png" alt=""><figcaption></figcaption></figure></div>

This page also shows the widget’s current configuration.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (424).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
Please note that [**Disconnect LINE**](disconnect-line.md) is located next to the widget status Overview page. Use it to disconnect LINE.

![](<../../.gitbook/assets/image (422).png>)
{% endhint %}

## Widget Management

If changes are needed, select **Manage Widget** in the top-right corner. The Manage page uses the same setup flow as [Add a Widget](add-a-widget.md).

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (423).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
Navigation tab & Save — use this to return to the Overview page at any time. Before leaving the page, select **Save** and confirm updates are applied.

![](<../../.gitbook/assets/image (354).png>)
{% endhint %}

### Configure LINE Setting

If LINE setting changes are needed, select **Edit LINE Settings**. In the LINE Settings window, the user can update the **LINE Channel Access Token** and **LINE Channel Secret**.
