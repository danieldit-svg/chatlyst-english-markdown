# Connect Facebook Messenger

{% stepper %}
{% step %}
Select **Connect with Messenger**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (983).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
In the Meta window, log in to your Facebook account (if required). When prompted, select **Continue as (User Name)** to proceed with the logged-in profile.

<div><figure><img src="../../.gitbook/assets/image (716) (1).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (717) (1).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
On the next screen, select **Opt in to current Pages only**. Check the boxes next to the specific Facebook Pages that need to be connected to Chatlyst.&#x20;

Select **Continue** to proceed.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (984).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Next, select **Opt in to current Businesses only**. Check the boxes next to the relevant Business accounts associated with the selected Pages.&#x20;

Select **Continue** to proceed.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (985).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Review the summary of access permissions requested by Chatlyst.&#x20;

Select **Save** to grant these permissions.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (986).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
A confirmation screen will appear indicating successfully linked on Meta's end.&#x20;

Select **Got it** to close the window and return to Chatlyst.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (989).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Back in the Chatlyst, a Select Facebook Page prompt will automatically appear.

Open the dropdown menu and select the specific Facebook Page to integrate with the Chat Widget.

Select **Connect Page** to finalize the setup.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (988).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
The widget status in Chatlyst changes from **Draft** to **Active**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (990).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

### Best Practice: Managing Multiple Pages

A single Chat Widget is designed to connect to one Facebook Page. If there are multiple Facebook Pages that need to be integrated into Chatlyst, it is highly recommended to add a separate Chat Widget for each individual Page. Setting up a dedicated widget for each page keeps customer conversations organized and makes incoming messages easier to manage.
