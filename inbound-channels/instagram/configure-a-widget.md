# Configure a Widget

In Instagram, select the widget from the list and select **Configure** to open the widget Overview page.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (953).png" alt="" width="375"><figcaption></figcaption></figure></div>

On this page, key stats include total conversations, total messages, and average session duration.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (954).png" alt=""><figcaption></figcaption></figure></div>

This page also shows the widget’s current configuration.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (955).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
Please note that [**Disconnect Instagram**](disconnect-instagram.md) is located next to the widget status Overview page. Use it to disconnect Instagram.

![](<../../.gitbook/assets/image (956).png>)
{% endhint %}

## Widget Management

If changes are needed, select **Manage Widget** in the top-right corner. The Manage page uses the same setup flow as [Add a Widget](add-a-widget.md).

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (957).png" alt=""><figcaption></figcaption></figure></div>

{% hint style="info" %}
Navigation tab & Save — use this to return to the Overview page at any time. Before leaving the page, select **Save** and confirm updates are applied.

![](<../../.gitbook/assets/image (958).png>)
{% endhint %}
