# Connect by Creating a Whatsapp Business Account

### Activate the widget

After you create a widget, the next page opens automatically so you can review the widget details.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (235).png" alt=""><figcaption></figcaption></figure></div>

### Connect by Creating a Whatsapp Business Account

{% stepper %}
{% step %}
Select **Connect with WhatsApp**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (237).png" alt=""><figcaption></figcaption></figure></div>

In the Meta window, log in to your Facebook account (if required). When prompted, connect with Effex, then select **Continue**.

{% hint style="info" %}
Note: Meta may take a few minutes to load this window. Please wait.
{% endhint %}

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmentd8f5a984 4974 445b 9abf ef0bde628014image.png" alt="" width="375"></div>
{% endstep %}

{% step %}
Select a **Business Portfolio.**

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmentb19144b8 0e4c 4577 9808 a9ae9477a6ceimage.png" alt="" width="375"></div>
{% endstep %}

{% step %}
In WhatsApp Business account, select **Create a WhatsApp Business account**, select **Next**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment49b33ba7 8d57 41b2 8840 655261ec5bf7image.png" alt="" width="375"></div>
{% endstep %}

{% step %}
Complete the business information:

* Select your business **Category**.
* Select your **Country**.
* Enter your **Website**.
* Select your **Time zone**.
* (Optional) Select **Show more options** to enter a Business description.
* Select **Next** to proceed.

{% hint style="warning" %}
Your website must be valid. This example uses Google for demonstration purposes.
{% endhint %}

<img src="../../.gitbook/assets/attachmenta5c74344 aea9 4faf b937 66441a62d921image.png" alt="" width="375">
{% endstep %}

{% step %}
Select **Add a new number** to create a WhatsApp Business account.

{% hint style="info" %}
If you select **Use a display name only**. WhatsApp will generate a virtual number for message-only use. You cannot initiate or receive calls or text messages.
{% endhint %}

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment45509baf ecda 4433 897e 2802753118bbimage.png" alt="" width="375"></div>
{% endstep %}

{% step %}
Enter your phone number and WhatsApp business display name.

* Choose a verification method. Select Text message, then select Next.

{% hint style="info" %}
Text messages (SMS) are often preferred over phone calls for verification because they provide a non-intrusive, instantly readable, and universally accessible method to deliver One-Time Passwords (OTPs) Textverified
{% endhint %}

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment242a6982 9bd7 4a33 978f 8323ba034fd7image.png" alt="" width="375"></div>
{% endstep %}

{% step %}
After you proceed, Meta sends a verification code to your phone.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmente377bb42 aa16 481a 9301 ae7b5694642aimage.png" alt="" width="375"></div>
{% endstep %}

{% step %}
Enter the WhatsApp code on your computer, then select Next.

{% hint style="warning" %}
Important Note: Do not delete this code. You need it for the next verification step in Chatlyst.
{% endhint %}

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment31cf60ff c0a0 4744 bc94 b54531ab3707image.png" alt="" width="375"></div>
{% endstep %}

{% step %}
Review the details you shared with Chatlyst，then select **Confirm**. Meta will connect the account.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmentf5788d08 80ce 4b81 b889 8ff4f35c0f9cScreenshot_2026 06 01_at_10.22.48_PM.png" alt="" width="375"></div>
{% endstep %}

{% step %}
When your account connects successfully, you see a confirmation message on your computer, select **Finish**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment82b81e2b 8e3b 4792 b4bf c323ca6bd7ddimage.png" alt="" width="375"></div>
{% endstep %}

{% step %}
In Chatlyst, enter the WhatsApp code you received earlier in the registration PIN window. Select **Register Number**.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment7e76e858 f043 4ae5 a173 52b67837f571Screenshot_2026 06 02_at_9.42.31_PM.png" alt="" width="375"></div>
{% endstep %}

{% step %}
In Chatlyst, the widget status changes from **Draft** to **Active**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (238).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
