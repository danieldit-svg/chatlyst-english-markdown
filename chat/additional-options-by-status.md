### Actions

#### Pin / Unpin

Use **Pin** to keep an important conversation at the top of the Thread List.

Pinning is helpful for conversations that require:

* Close monitoring
* Urgent follow-up
* Frequent reference

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (204).png" alt="" width="563"><figcaption></figcaption></figure></div>

{% hint style="info" %}
Pinned conversations still follow the current Conversation Label and any active filters. If a pinned conversation does not match the selected label or filters, it will not appear in the Thread List.
{% endhint %}

To unpin a conversation:

1. Open Additional Options.
2. Select **Unpin**.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (205).png" alt="" width="563"><figcaption></figcaption></figure></div>

{% hint style="info" %}
Pinned conversations are highlighted in light yellow in the Thread List.

![](<../.gitbook/assets/image (206).png>)
{% endhint %}

#### Snooze

Use **Snooze** to temporarily pause a conversation so it does not require immediate attention.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (207).png" alt="" width="563"><figcaption></figcaption></figure></div>

After selecting Snooze, the Snooze Conversation window appears.

<div align="center" data-with-frame="true"><img src="../.gitbook/assets/attachmentae8aa592 b7e1 4c5a 9c5b 578019fadfb1Screenshot_2026 04 23_at_5.45.32_PM (1).png" alt="" width="375"></div>

1. Set the resume date and time.
2. (Optional) Add a reason or note.
3. Select **Confirm** to apply the snooze.

When a conversation is snoozed, it moves lower in the Thread List because it is treated as lower priority while paused.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (208).png" alt=""><figcaption></figcaption></figure></div>

When the snooze time passes, the status updates from Snoozed to **Previously Snoozed**.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (209).png" alt=""><figcaption></figcaption></figure></div>

#### Unsnooze

To unsnooze a conversation (Snoozed or Previously Snoozed):

1. Open Additional Options.
2. Select **Unsnooze**.

After unsnoozing:

* The conversation resumes in the Thread List.
* The status updates to Pending Response.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (215).png" alt="" width="563"><figcaption></figcaption></figure></div>

#### Hand Back to AI

This feature requires additional setup before it can be enabled and shown on the Dashboard. To learn what is required, select **Contact Effex** for details.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (214).png" alt="" width="563"><figcaption></figcaption></figure></div>

#### Close

Use **Close** when the conversation is complete and considered resolved.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (216).png" alt="" width="563"><figcaption></figcaption></figure></div>

{% hint style="info" %}
Closed conversations cannot be reopened. Confirm the thread is fully resolved before selecting Close.
{% endhint %}
