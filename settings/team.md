# Team

Use Team to manage workspace members and invitations. Add or remove people, assign roles and permissions, and review pending invitations.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (914).png" alt=""><figcaption></figcaption></figure></div>

***

### Invite Team Members

{% stepper %}
{% step %}
Select **Invite Member.**

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (915).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Enter the team member’s details (First Name, Last Name and Email Address) and select the correct role based on the access level you want to grant. Select **Send Invitation**.

{% hint style="info" %}
Roles in Chatlyst:

* **Member** — basic access for managing chats.
* **Admin** — broader administrative access to most features, excluding Billing.
* **Owner** — full access.
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (916).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

***

### Member Onboarding

{% stepper %}
{% step %}
The invited member receives an email invitation with instructions for joining the workspace and completing the initial sign-in steps.

<div data-with-frame="true"><img src="../.gitbook/assets/attachment362ce5ea 355a 47cc be60 06a8d5bdf5bdScreenshot_2026 04 23_at_9.41.31_PM (2).png" alt="" width="563"></div>
{% endstep %}

{% step %}
On first login, the invited member reviews and completes account details and sets a password to finish the initial account setup.

<div data-with-frame="true"><img src="../.gitbook/assets/attachmentb5f43912 1094 4cfe bf1b 2707f3bf1fecScreenshot_2026 04 23_at_9.50.54_PM (2).png" alt="" width="563"></div>
{% endstep %}

{% step %}
The invited member can then log in.

<div data-with-frame="true"><img src="../.gitbook/assets/attachment424ad2db f185 4242 a11f 23305828c99aimage (2).png" alt="" width="563"></div>
{% endstep %}

{% step %}
The **Team Member** **list** and **Invitations** **list** update automatically after the invited member login.&#x20;

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (917).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
The Team Member list shows the full list of workspace members and key details for each person, including role and current status.

<div align="left" data-with-frame="true"><img src="../.gitbook/assets/attachmentff11c019 f7e9 4150 8699 83e8f1cb4b05image (2).png" alt=""></div>
{% endstep %}

{% step %}
The Invitations list shows the status of each invite so the owner can confirm whether an invite is pending, accepted, or needs to be resent.

<div data-with-frame="true"><img src="../.gitbook/assets/attachment12f4f650 6c81 4ed9 80ed d4a18c47314eimage (2).png" alt=""></div>
{% endstep %}

{% step %}
If the latest changes do not appear right away, select **Refresh** to fetch the most up-to-date information.

<div data-with-frame="true"><img src="../.gitbook/assets/attachmentc60646fa e2c2 47d0 9a4b db7517ee6458image (2).png" alt=""></div>
{% endstep %}
{% endstepper %}

### Mange Access

The following guide shows how to manage a member’s access:

{% stepper %}
{% step %}
Select the member and open the menu next to the member’s name.

<div data-with-frame="true"><img src="../.gitbook/assets/attachment0249d2c8 cfc2 4c82 a509 335ca65c6495image (2).png" alt=""></div>
{% endstep %}

{% step %}
Use the menu to:

* Update the member’s role and access level
* Suspend the member to temporarily remove access
* Remove the member from the workspace

<div data-with-frame="true"><img src="../.gitbook/assets/attachment8d3184ac 9293 4d6a 8c30 0f8dcba6fdafc0809156 c524 410f 8529 ae7d3a4aa3f9 (2).png" alt=""></div>
{% endstep %}
{% endstepper %}

***

### Manage Invitations

The following guide shows how to manage invitations:

{% stepper %}
{% step %}
Select the invitation and open the menu next to the invited person’s name.

<div data-with-frame="true"><img src="../.gitbook/assets/attachment4ee13e5a 79d5 460e b85f d96a099630f0image (2).png" alt=""></div>
{% endstep %}

{% step %}
Use the menu to:

* **Resend Invitation** (if the original email was missed or expired).
* **Revoke Invitation** (if it was sent in error or is no longer needed).

<div data-with-frame="true"><img src="../.gitbook/assets/attachmentc1c80183 db1c 488e 8cc5 cff4019df77b20472384 5965 424b 8f3e 32999906d016 (2).png" alt=""></div>
{% endstep %}
{% endstepper %}
