# Company

Use Company to manage and update core business information. This data can be configured during the initial account creation process or adjusted at any time through the Settings.

### Available Profile Settings

The following details can be updated within the company profile:

* **Company Icon**: A visual logo representing the business. This icon can be configured to display within the website embed widget.&#x20;
  * To upload a company icon, select an image file from the local computer and upload it. Please refer to the [Website Embed](../inbound-channels/website-embed/add-a-widget.md#appearance) guide for instructions on setting the icon in the widget.&#x20;

{% hint style="info" %}
The company icon supports PNG, JPG, and SVG file formats. A square aspect ratio is recommended for the best display results.
{% endhint %}

* **Company Name**: The official title or name of the organization.
* **Website**: The primary web address associated with the business.
* **Email Communication Language**: The default language preference for receiving automated system notifications and account emails.
* **Description**: A brief summary or overview outlining the company's purpose or services.

#### How to Save Updates

To ensure any modifications to the company profile are successfully applied, follow these steps:

1. Complete the desired updates within the respective text fields or image upload areas.
2. Review the newly entered information to confirm all details are accurate.
3. Select the **Save Changes** to apply and finalize the updates to the workspace.
