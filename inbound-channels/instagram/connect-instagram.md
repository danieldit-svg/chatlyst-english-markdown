# Connect Instagram



{% stepper %}
{% step %}
Select **Connect with Instagram**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (712).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
In the Meta window, log in to your Facebook account (if required), then select **Continue** to proceed with the logged-in profile.

<div><figure><img src="../../.gitbook/assets/image (716).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (717).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
On the next screen, select **Opt in to current Pages only**. Check the boxes next to the specific Facebook Pages that need to be connected to Chatlyst.&#x20;

Select **Continue** to proceed.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (720).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Next, select **Opt in to current Businesses only**. Check the boxes next to the relevant Business accounts associated with the selected Pages.&#x20;

Select **Continue** to proceed.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (722).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
On the following screen, select **Opt in to current Instagram accounts only**. Check the boxes next to the specific Instagram accounts intended for use with Chatlyst to continue the integration process.&#x20;

Select **Continue** to proceed.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (735).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Review the summary of access permissions requested by Chatlyst.&#x20;

Select **Save** to grant these permissions.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (736).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
A confirmation screen will appear indicating the Pages have been successfully linked on Meta's end.&#x20;

Select **Got it** to close the window and return to Chatlyst.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (737).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Back in the Chatlyst, a **Select Instagram Account** window will automatically appear.

Before proceeding to the next step, review the provided guide to complete all mandatory configurations directly within the Instagram mobile spp.

{% hint style="warning" %}
All required settings within the Instagram mobile app must be finished before moving forward to ensure a successful integration.
{% endhint %}

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (738).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Setup Instagram account on mobile app.&#x20;

1. Open the **Instagram app** on a mobile phone.
2. Navigate to the user **Profile** (the icon in the bottom right corner).
3. Select the **menu icon (three horizontal lines)** located at the top of the screen.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (740).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Scroll to find **Account type and tools**, then select **Messaging tools**.

<div><figure><img src="../../.gitbook/assets/image (743).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (742).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select **Message controls**.&#x20;

1. Locate the setting labeled **Allow access to messages** and toggle it to enable setting.
2. On the same screen, ensure that **Everyone** is checked for both **Who can send you message requests** and **Who can add you to group chats**.

<div><figure><img src="../../.gitbook/assets/image (744).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (745).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
After successfully updating the required settings within the Instagram mobile app, return to the Chatlyst to complete the setup.

1. Select the Instagram account to be connected from the **dropdown menu**.&#x20;
2. Select the acknowledgment **checkbox**. This action confirms to the system that all required settings have been successfully completed within the Instagram mobile app.
3. Select the **Connect Account** to finalize the integration.

<div><figure><img src="../../.gitbook/assets/image (748).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (749).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
