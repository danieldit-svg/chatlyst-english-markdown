# Disconnect Facebook Messenger

{% stepper %}
{% step %}
Go to **Inbound Channel**.


{% endstep %}

{% step %}
Select the widget you want to disconnect from Facebook Messenger, then select **Configure**.


{% endstep %}

{% step %}
Select **Disconnect Messenger**.


{% endstep %}

{% step %}
When the browser confirmation window appears, select **OK** to proceed.


{% endstep %}

{% step %}
Confirm the widget status changes from **Active** to **Draft**.


{% endstep %}
{% endstepper %}
