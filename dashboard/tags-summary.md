### AI Complaint Radar Summary

The AI Complaint Radar Summary is an automated advisory report generated by Chatlyst's AI. It analyzes recent customer interactions to identify risks and suggest workflow improvements.

{% hint style="info" %}
**Requirement:** To view this summary, the [Chatlyst Radar](../settings/conversation-tags.md) feature must be enabled in the system settings.
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (828).png" alt=""><figcaption></figcaption></figure></div>

#### Key Information Displayed in the Summary

The summary report provides constructive suggestions to help manage customer complaints effectively. The report includes the following types of guidance:

* **Data Analysis**: Summarizes recent complaint trends, indicating whether the overall volume of complaints has increased or decreased compared to the previous data.
* **Mitigation & SOP Recommendations**: Offers actionable advice generated by the AI to improve system performance and support processes.&#x20;

{% hint style="info" %}
**Last Updated**: Located at the top-right of the summary, this displays a timestamp showing exactly when the latest analysis was generated. The system automatically updates this report every 12 hours based on the [Chatlyst Radar Monitoring Frequency](../settings/conversation-tags.md) setting.
{% endhint %}

### Tags Library and Tagged Conversations

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (939).png" alt=""><figcaption></figcaption></figure></div>

#### **Tags Library**&#x20;

The Tags Library acts as a specific filter for the analytics dashboard. It displays a complete list of all active tags alongside the exact number of times each tag has been applied.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (940).png" alt="" width="381"><figcaption></figcaption></figure></div>

#### Tagged Conversations

The Tagged Conversations section displays a detailed list of conversations that match the filters selected in the Tags Library.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (941).png" alt="" width="563"><figcaption></figcaption></figure></div>

#### How to Filter and Review Conversations

{% stepper %}
{% step %}
Select a specific tag or enter a keyword in the Tags Library search bar to apply a filter.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (942).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Review the updated list of conversations in the **All Tagged Conversations** section.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (943).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select a specific conversation and click the **Go to chat** to read the full conversation in [Chat](https://app.gitbook.com/s/BW7n4ClAhZvbgvusylCd/chat).

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (944).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

#### Navigation and Tag Management

**Navigating Between Pages**

All Tagged Conversations appear in a standard list format. If the list spans multiple pages, select the **Previous** or **Next** buttons located at the bottom of the screen to move between pages.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (945).png" alt="" width="563"><figcaption></figcaption></figure></div>

**Managing Tags**

To edit, create, or update current tags, select the **Gear** Icon to open Conversation Tags. Refer to the [Conversation Tags](../settings/conversation-tags.md) guide for more detailed instructions.
