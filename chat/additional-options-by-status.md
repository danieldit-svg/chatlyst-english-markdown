#### Pin and Unpin

Use the **Pin** action to keep an important conversation fixed at the top of the Thread List. Pinned conversations are highlighted in light yellow.

Pinning is helpful for conversations that require close monitoring, urgent follow-up, or frequent reference.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (866).png" alt="" width="563"><figcaption></figcaption></figure></div>

{% hint style="info" %}
Pinned conversations still follow the active filters and labels. If a pinned conversation does not match the currently selected filter, it will not appear in the list.
{% endhint %}

How to **Unpin** a Conversation:

1. Open the **Additional Options** menu in the top-right corner of the conversation panel.
2. Select **Unpin**.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (867).png" alt="" width="563"><figcaption></figcaption></figure></div>

***

#### Snooze and Unsnooze

Use the **Snooze** action to temporarily pause a conversation so it does not require immediate attention. When snoozed, the conversation drops lower in the Thread List, as it is treated as a lower priority while paused.

**How to Snooze a Conversation:**

{% stepper %}
{% step %}
Select **Snooze** to open the Snooze Conversation window.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (868).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Set the desired resume date and time.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (870).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Add an optional reason or internal note. Select **Snooze** to apply or select **Cancel** to discard.

{% hint style="info" %}
When the scheduled snooze time passes, the conversation status automatically updates from **Snoozed** to **Previously Snoozed**.
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (872).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

**How to Manually Unsnooze:**

1. Open the Additional Options menu.
2. Select **Unsnooze**.

{% hint style="info" %}
After unsnoozing manually, the conversation resumes its normal position in the Thread List, and the status updates to **Pending Response**.
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (873).png" alt="" width="563"><figcaption></figcaption></figure></div>

#### Assign to Agent

Use the assignment feature to manually manage who is responsible for handling a specific chat.

{% hint style="info" %}
If automatic routing is preferred over manual assignment, the system can distribute conversations automatically based on specific settings. Refer to the [Assignment Rules](../settings/assignment-rules.md) guide for detailed instructions on configuring automatic chat routing.
{% endhint %}

**How to Assign a Conversation:**

{% stepper %}
{% step %}
Select **Assign to Agent** to open the Assign Conversation window.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (874).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Open the dropdown list and select the agent to assign

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (876).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
&#x20;Select **Assign** to apply or select **Cancel** to discard.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (877).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

**How to Clear an Assignment (Unassign from an assigned agent):**

{% stepper %}
{% step %}
Select **Assign to Agent** to open the Assign Conversation window.

<figure><img src="../.gitbook/assets/image (879).png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Open the dropdown list and select **Unassigned (Clear Assignment)**. This window also displays the current assignee.

Select **Unassign** to apply or select **Cancel** to discard.&#x20;

{% hint style="info" %}
Once the currently assigned team member is removed, the ticket automatically reverts to an **Unassigned** status.&#x20;
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (881).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

#### Hand Back to AI

A live agent can return a conversation to the automated chatbot at any time. When the conversation hand back to AI, the conversation status automatically updates to **Bot Handling**.

{% hint style="warning" %}
When a conversation is handed back, the chatbot **does not read or understand the messages exchanged while the live agent was involved**. The chatbot will lack the context of that specific interaction.
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (882).png" alt="" width="563"><figcaption></figcaption></figure></div>

#### Close

Use the **Close** action to end the chat session when the conversation is complete and the customer's issue is fully resolved.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (883).png" alt="" width="563"><figcaption></figcaption></figure></div>

#### Reopen

**Reopen** allows users to resume a past conversation with a customer after a period of inactivity. Reengaging the customer this way keeps the entire chat history consolidated within a single, continuous thread, making it easier to review past interactions.

{% hint style="warning" %}
**Channel Restrictions for Reopening**

The ability to reopen a conversation depends entirely on the rules of that specific channel:

* **Website Widget:** A conversation cannot be continued if the customer has closed the chat window on their browser.
* **Facebook Messenger, Instagram, and LINE:** Conversations on these platforms can be reopened at any time.
* **WhatsApp:** WhatsApp enforces a strict 24-hour messaging window. If 24 hours have passed since the customer's last message, standard text replies are blocked. To reopen a WhatsApp conversation after this window, a pre-approved [**WhatsApp Template Message**](../inbound-channels/whatsapp/whatsapp-template-messages.md) must be sent to reengage the customer.
{% endhint %}
