# Configure a Widget

In WhatsApp, select the widget from the list and select **Configure** to open the widget Overview page.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmentbe3666a5 f1ef 42d6 9dc5 b57522ce0081image.png" alt="" width="375"></div>

On this page, key stats include total conversations, total messages, and average session duration.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment23084338 53be 4944 b961 43b6d701e449image.png" alt=""></div>

This page also shows the widget’s current configuration.

<div data-with-frame="true"><img src="../../.gitbook/assets/attachmente8c9ef16 6d90 4ee9 927c 0635b5916fb9image.png" alt=""></div>

{% hint style="info" %}
Please note that **Disconnect WhatsApp** is located next to the widget status Overview page. Use it to disconnect WhatsApp.

![](<../../.gitbook/assets/image (230).png>)
{% endhint %}

## Widget Management

If changes are needed, select **Manage Widget** in the top-right corner. The Manage page uses the same setup flow as [Add a Widget](add-a-widget.md).

<div data-with-frame="true"><img src="../../.gitbook/assets/attachment838b2d8a ae22 4ead 93d7 38a58c3f3aa5image.png" alt=""></div>

{% hint style="info" %}
Navigation tab — use this to return to the Overview page at any time. Before leaving the page, select **Save** and confirm the toggle is set correctly so changes are not lost.

![](<../../.gitbook/assets/image (233).png>)
{% endhint %}

{% hint style="info" %}
Please note that the toggle switch and Save button are located in the top-right corner of the management page. Select **Save** after making changes and confirm the toggle is set correctly so updates are applied.

![](<../../.gitbook/assets/image (234).png>)
{% endhint %}
