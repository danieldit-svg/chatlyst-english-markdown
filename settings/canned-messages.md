# Canned Messages

Canned Messages are pre-written replies that allow users to quickly insert frequently used phrases into active conversations. This feature relies on a **Short Code**, which is a brief text shortcut assigned to a longer message.

{% hint style="info" %}
To trigger a Canned Message during a chat, type a forward slash (`/`) followed immediately by the exact short code in the conversation input box. For further details on how to use this feature while communicating with customers, please refer to the [Conversation Panel](../chat/conversation-panel.md) guide.
{% endhint %}

### **How to Create a New Canned Message**

{% stepper %}
{% step %}
Select **Add Canned Message**.&#x20;

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (899).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
System will prompt a Create Canned Message window, enter a unique identifier in the **Short Code** field.

{% hint style="info" %}
If managing conversations in multiple languages, add a language abbreviation to the start of the Short Code to keep them organized _(for example, use `en-welcome` for English or `zh-welcome` for Chinese)._
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (900).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Enter the full text of the reply in the **Message Content** field.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (901).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select **Add Canned Message** to save the new shortcut, or select **Cancel** to discard the entries.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (902).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

***

### Viewing Existing Canned Messages

#### How to Edit a Canned Message

{% stepper %}
{% step %}
Locate the specific Canned Message you wish to modify in the configuration list. Select the **Pen** icon located in the **Actions** column to open the editing menu.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (903).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Update the Short Code or the Message Content as necessary.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (904).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select **Save Changes** to apply, or select **Cancel** to discard.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (905).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

#### How to Delete a Canned Message

{% stepper %}
{% step %}
Locate the specific Canned Message you wish to remove in the configuration list. Select the **Bin Icon** located in the **Actions** column. A confirmation window will appear.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (907).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select **Delete** to confirm the removal, or select **Cancel** to discard.

{% hint style="warning" %}
Deleting a Canned Message is a permanent action that cannot be undone.
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (906).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
