# Conversation Panel

The Conversation Panel is the main workspace used to review message history, manage customer interactions, and send replies. Within this panel, a team member can [join a chat](conversation-panel.md#join-a-conversation), [use quick actions](conversation-panel.md#use-additional-options), [review customer information](conversation-panel.md#review-customer-details), and [submit feedback](conversation-panel.md#provide-training-feedback) to improve the system.

### Join a Conversation

A live support agent can intervene and take control of a customer chat at any time. This includes stepping into active conversations that are currently being managed by the automated bot (indicated by the **Bot Handling** status).

#### How to Join a Chat

{% stepper %}
{% step %}
Click the **Join Chat** button located at the bottom of the screen.

{% hint style="info" %}
Taking this action activates the Input Field, the conversation status will automatically change to **Pending 1st Response**.&#x20;
{% endhint %}

<div><figure><img src="../.gitbook/assets/image (857).png" alt=""><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/image (858).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Available Tools After Joining**

Once an agent joins the chat, the system unlocks several tools to help manage the customer inquiry effectively.
{% endstep %}

{% step %}
1.  **Send Replies:** Use the Input Field to communicate directly with the customer. The following response options are available:

    * **Text Messages**: Type and send standard text replies.

    <div data-with-frame="true"><figure><img src="../.gitbook/assets/image (859).png" alt="" width="563"><figcaption></figcaption></figure></div>

    * **Multimedia**: Attach and send files, such as images or documents, directly to the customer.

    <div data-with-frame="true"><figure><img src="../.gitbook/assets/image (862).png" alt="" width="563"><figcaption></figcaption></figure></div>

    * **Canned Messages**: Use pre-written text shortcuts to quickly insert answers to common questions. Refer to the [Canned Messages](../settings/canned-messages.md) guide for more details.

    <div data-with-frame="true"><figure><img src="../.gitbook/assets/image (860).png" alt="" width="563"><figcaption></figcaption></figure></div>
2. **Leave Internal Notes**: Switch the Input Field from standard messaging to the **Note** function. This feature allows agents to write internal memos, reminders, or updates for other team members to read.&#x20;

{% hint style="info" %}
Internal notes are strictly private and will never be visible to the external customer.
{% endhint %}

<div><figure><img src="../.gitbook/assets/image (863).png" alt=""><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/image (865).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

### Confirm the Conversation Status

The current condition of the conversation status dictates what actions are available. This status is always displayed in the top-right corner of the Conversation Panel.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (854).png" alt="" width="563"><figcaption></figcaption></figure></div>

### Additional Options

The Additional Options menu provides quick access to standard chat management tools. Locate this menu in the top-right corner of the panel to perform the various actions. Refer to the [Additional Options by status](additional-options-by-status.md) guide for more details.&#x20;

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (855).png" alt="" width="563"><figcaption></figcaption></figure></div>

***

### Review Customer Details

Select the Customer Details icon (located in the top-right corner, next to the Additional Options menu) to open a comprehensive profile of the current customer.&#x20;

This view provides essential context, including: Contact Info, Platform Context and Notes etc. Refer to the [Customer Details](customer-details.md) guide for more details.&#x20;

### Provide Training Feedback

To improve the accuracy of the automated system, users can submit training feedback directly on individual messages within the Conversation Panel.

{% stepper %}
{% step %}
Review the specific responses sent by the bot or the live agent within the chat history. If a response is unhelpful, select the option to submit negative feedback on that specific message.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (853).png" alt="" width="563"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
A Provide Training Feedback window will immediately appear on the screen. Follow the prompts in this window to submit corrections and train the system on how to handle similar questions in the future. Refer to the [Train & Test bot](https://app.gitbook.com/s/BW7n4ClAhZvbgvusylCd/train-and-test-bot) guide for more details.&#x20;

<div align="center" data-with-frame="true"><figure><img src="../.gitbook/assets/image (70).png" alt="" width="359"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
