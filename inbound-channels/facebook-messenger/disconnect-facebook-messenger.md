# Disconnect Facebook Messenger

{% stepper %}
{% step %}
## Disconnect Facebook Messenger in Chatlyst

1. Go to **Inbound Channel**.
2. Select the widget you want to disconnect from Facebook Messenger, then select **Configure**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (991).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Select **Disconnect Messenger**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (992).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
When the browser confirmation window appears, select **OK** to proceed.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (993).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
Confirm the widget status changes from **Active** to **Draft**.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (994).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
